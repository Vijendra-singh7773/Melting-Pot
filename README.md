# Melting Pot Djibouti — Restaurant Website

A responsive, animated one-page restaurant website built with plain HTML, CSS and JavaScript. It uses the supplied restaurant and food images.

## Run locally
1. Extract the ZIP.
2. Open `index.html` in a browser, or run a local server from this folder:
   - `python -m http.server 8000`
   - Visit `http://localhost:8000`

## Customize
- Update content and links in `index.html`.
- Change colors, layout, and animations in `style.css`.
- Replace photos in `assets/` (keep filenames or update the image paths).
- Phone and WhatsApp links are set to +253 21 35 03 99.

This is a front-end demo. Reservation calls and WhatsApp links open the relevant contact actions; no booking database/backend is included.
